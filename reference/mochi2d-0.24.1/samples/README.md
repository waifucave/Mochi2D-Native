# Sample models

## `mochi/` — «Mochi»

A small model to try: `mochi.model3.json`, `mochi.moc3` (version 5), its texture, display info,
physics for the front hair and a three-second idle motion. Its parameters use the usual IDs
(`ParamAngleZ`, `ParamEyeLOpen`, `ParamEyeROpen`, `ParamMouthOpenY`, `ParamHairFront`), and its
settings name the EyeBlink and LipSync groups. It uses neither glue nor blend shapes.

It is the example model of Mochi Maker's getting-started guide, copied unchanged from Mochi
Maker's `samples/mochi/`. Mochi Maker's own code draws its art and builds and exports it; no
third-party art or model is involved. It is under the MIT License, like the rest of this
repository.
