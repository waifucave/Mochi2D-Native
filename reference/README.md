# The reference

`mochi2d-0.24.1/` is the source of Mochi2D 0.24.1, the project's own web
runtime (MIT), as released. Mochi2D Native ports its behavior, and
Mochi2D's results are the bar for conformance: the cross-checks run it
beside Mochi2D Native and compare the two.

Read and run it freely, but don't edit it: each new Mochi2D release
replaces the folder as released, and its `CHANGELOG.md` says what changed.
