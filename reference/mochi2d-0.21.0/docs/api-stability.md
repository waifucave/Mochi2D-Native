# API stability

Every public export of the four entry points, each with a stability mark.
The lists are generated from the build's type declarations
(`npm run build:lib`, then `npm run api-list`), and
`test/api-stability.test.ts` fails when an export appears or disappears
without them changing.

| Mark         | Meaning                                                                                                         |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| stable       | Part of the 1.0 API: it changes incompatibly only in a new major version ([docs/versioning.md](versioning.md)). |
| experimental | Usable, but may still change in a minor version, always noted in `CHANGELOG.md`.                                |
| deprecated   | An old name kept for a while after a rename, with the new name in its doc comment. None at the moment.          |

What is still experimental, and why:

- **PixiJS** (`mochi2d/pixi`'s `MochiSprite` and its types): new in 0.13.0,
  and its options and events may still follow what apps need in a Pixi
  scene.
- **Live motion sync** (the analysis, the driver, voice calibration and
  synthesis): Mochi2D's own analysis, whose results are rated by ear and
  may change. Reading and writing `.motionsync3.json` files is stable.
- **Lower-level building blocks** (`Animator`, `loadModelBundle`,
  `loadAnimationAssets` and their types): `ModelRuntime` is the stable way
  to load and animate a model, and these follow its insides.
- **Evaluation switches** (`EvaluationOptions`, the `evaluation` option of
  `ModelInstance` and `RuntimeOptions`): new in 0.21.0, for evaluating
  without glue or blend shapes.
- **Conformance results** (`scenarioResult`, the scenario and result types,
  `snapshotInstance`, `formatResultJson`): their formats are at version 0.
  The framing helpers (`frameImage`, `imagePosition`, `outputPosition`) are
  stable.

Items (`MochiItem` and its layouts) became stable in 0.19.0. The names
renamed in 0.16.0 lost their old forms in 0.19.0; [docs/migration.md](migration.md)
lists every rename and removal since 0.10.0.

`mochi2d/node` has everything in `mochi2d/headless`, and `mochi2d/pixi`
everything in `mochi2d`; the "Entry points" column names each one an export
