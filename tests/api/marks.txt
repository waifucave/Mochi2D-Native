# Stability marks of the C API (include/mochi2d.h), by name: the first
# pattern (fnmatch) that matches a function, type or constant gives its mark.
# tests/api/api_list.py writes docs/api-stability.md from the header and
# these rules; the api-list test fails when the two disagree.
#
# experimental: usable, but may still change in a minor version (noted in
# CHANGELOG.md). stable: from 1.0 on, changed
# incompatibly only in a new major version.
