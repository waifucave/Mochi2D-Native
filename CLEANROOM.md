# How Mochi2D Native was written

Mochi2D Native is a port of Mochi2D, the project's own runtime (MIT), written
without Live2D Inc.'s software.

- Its code was written by AI coding agents directed by the maintainer. They
  worked only from the project's own written briefs, Mochi2D's source, tests
  and documentation (in `reference/`), model data files, general programming
  knowledge and permissively licensed libraries.
- They did not view, install or run any Live2D SDK component or manual, or any
  third-party implementation of the format, and they did not use Live2D Inc.'s
  sample models.
- How Mochi2D itself was written is described in its own CLEANROOM.md.
- The briefs and reports of this process are kept in a private record.
- Contributions follow the same rule: see CONTRIBUTING.md.
